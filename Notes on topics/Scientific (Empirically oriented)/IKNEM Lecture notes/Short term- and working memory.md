##### Sensory memory
There is an unlimited capacity of information, however, there is a very limited temporal capacity
- Iconic memory - "Efterbillede" at 0,5 sceonds ish
- Eccoic memory - "Playback" at 2 seconds ish (Unconscious listening) 

##### Short time memory
Mostly consicous although some theorize that there is unconscious parts as well.
- Limited capacity (4 elements)
	- Miller (1965) - 7 +/- 2
- Easily forgotten when distracted
- Uasually kept for seconds, but theoretically no temporal limit
- Separate for each of the senses
- Cross modal

##### Whole report
- Sensory vs short time memory
- Averbach and Coriell shows that the sensory memory captures quite a larger amount of elements than we percieve, but these can be acces by cuing after the stimuli at different points
